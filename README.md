# Mega Blog

Mega Blog is a blogging application built with React and Appwrite. Users can create an account, write blog posts, edit their posts, and explore content shared by other users.

## Features

- User signup and login
- Create and publish blog posts
- Edit and delete posts
- View all published posts
- View individual post details
- Protected routes
- Rich text editor
- Image upload and management

## Tech Stack

- React
- Vite
- Tailwind CSS
- Appwrite
- Redux Toolkit
- React Router
- React Hook Form
- TinyMCE

## About

This project was built to practice React, state management, authentication, routing, and backend integration using Appwrite.
